# LIYO MVP

LIYO is a Flutter starter for a social app where users can share ideas, photos, videos and later audio.

## Current MVP
- Home feed
- Create text/idea post
- Pick photo from gallery
- Pick video from gallery
- Like counter
- Comment/share UI placeholders
- Search, Alerts and Profile tabs
- Android + iOS Flutter target

## Next production steps
1. Connect Firebase Authentication.
2. Add Firestore posts, likes, comments and follows.
3. Add Firebase Storage for photos/videos/audio.
4. Add real video player and compression.
5. Add chat and notifications.
6. Add report/block/moderation and admin panel.
7. Add privacy policy/terms and monetization.
8. Configure Android and iOS signing and publish accounts.

## Run
Install Flutter, then:
flutter pub get
flutter run

For Firebase:
flutterfire configure
